# SmartStock Front-end

Este projeto contém o Front-end da plataforma SmartStock.
Foi construído com React, Vite, Tailwind CSS, Lucide React (ícones) e Recharts (gráficos).

## Como executar:
1. Certifique-se de ter o Node.js instalado.
2. Abra o terminal na pasta descompactada e execute:
   npm install
3. Para rodar o projeto, execute:
   npm run dev
